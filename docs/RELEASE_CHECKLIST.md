- [ ] Creator attribution and community contribution policy reviewed
- [ ] GitHub repository, npm package, domain and trademarks cleared (none reserved by this artifact)
- [ ] Dependency licenses scanned and license notices included
- [ ] Offline CLI tests green on Linux, Windows and macOS CI; evidence attached
- [ ] Security review and threat-model gaps disclosed
- [ ] No secrets, tokens, private data or proprietary source in fixtures
- [ ] External integrations either tested with exact versions or labeled planned
- [ ] README quickstart verified on a clean clone
- [ ] Changelog, roadmap, badges, sample reports and issue templates finalized
- [ ] Sample rollback exercise honestly labeled static vs tested
- [ ] No claim of guaranteed production safety or certified migration support
