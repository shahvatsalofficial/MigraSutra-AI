Functional Specification

Commands#

CommandPurposeWrites
doctorPrint version, platform, implemented and planned featuresstdout
versionPrint the versionstdout
scan --root P --out F [--format json,md,html]Static scanone file
plan --root P --scan F --target T --out FPlan for one changeone file
rehearse --root P --plan F --out FTemp-dir rehearsalone file
gate --plan F --rehearsal F --out F [--evidence F]Release-gate reviewone file
compare --before F --after F --out FDiff two scansone file
render --input F --out F --format md,htmlRe-render any reportone file
audit --root P --out DIR [--target T] [--fail high]scan + plan + rehearse + gate in one stepaudit.json, audit.md, audit.html
skills --host H --root PCopy skills into an IDE pathskill folders
serve --report F --port NLocalhost read-only APInone

Targets: npm:package@1.2.3 or node:22. Anything else is refused.

Exit codes: 0 success, 1 audit --fail high found a high finding, 2 error.

Inputs read#

Only these root files are read: package.json, lockfiles, requirements.txt, pyproject.toml, go.mod, pom.xml, build.gradle(.kts), composer.json, Dockerfile, .tool-versions, plus .sql files under migrations, db/migrations, prisma/migrations and database/migrations. .env and other files are never read.

Comments and single-quoted strings are blanked before matching.

Verdicts#

NO_GOA high-severity static finding exists, or the rehearsal failed. Fix this first.
REVIEW_REQUIREDThe best possible result. A person must review. Tests and rollback were not run.
UNVERIFIED_EXTERNALEvidence you imported. It is recorded and never raises the verdict.
GO_CANDIDATEReserved for a future policy with verified tests. Not implemented.
VerdictWhen
NO_GOAny high static finding, or the static rehearsal failed
REVIEW_REQUIREDEverything else. Tests and rollback are always NOT_RUN, so this is the ceiling
GO_CANDIDATENot implemented. Reserved for a future policy with verified test evidence

Imported evidence passed to gate --evidence is labelled UNVERIFIED_EXTERNAL and never raises the verdict.

Acceptance behaviors#

  • A plan whose package.json hash differs from the scan is refused as stale.
  • A plan whose action no longer matches its target is refused.
  • A dependency value that contains credentials makes planning fail.
  • Symlinked files and directories are skipped or refused.
  • Files over 1 MiB are rejected, never streamed.
