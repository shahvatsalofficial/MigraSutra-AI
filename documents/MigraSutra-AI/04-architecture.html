Architecture

Context#

The CLI calls a read-only core. The core reads allow-listed files, writes only to a temp folder during rehearsal, and returns JSON, Markdown or HTML. There is no cloud service.

Shell

Parses arguments, writes report files, sets exit codes.

packages/clipackages/server (127.0.0.1, token)skills installer

Core

Read-only analysis. No network and no process execution.

scanRepositorycreatePlanrehearsePlanreleaseGatecompareScansauditRepositoryMarkdown and HTML renderers

Guidance

Instructions for AI coding hosts. The CLI runs without them.

20 skillsagentsrulespoliciesworkflowsschemas

Runtime

Node.js 22+ built-ins only. Zero dependencies. No telemetry.

The tool does

  • Read allow-listed filesmanifests, Dockerfile, SQL migrations
  • Hash and matchdeterministic rules, stable evidence IDs
  • Write reportsonly where you point --out
  • Rehearse in a temp folderdeleted afterwards

The tool never

  • Runs your codeno installs, scripts, tests or migrations
  • Calls the internetno cloud, no telemetry, no keys
  • Edits your sourcetests compare bytes before and after
  • Reads .env filesunlisted files are ignored

There is no cloud service, no telemetry and no model call in the product.

Lifecycle#

scan.json

Findings with file, line, rule ID and a SHA-256 of each source.

plan.json

One field change, its baseline hash, prerequisites and rollback notes.

rehearsal.json

Before and after hashes. Tests and rollback are marked as not run.

gate.json

NO_GO or REVIEW_REQUIRED with every reason listed.

Each hop carries hashes. The plan binds to the scan's package.json hash. The gate binds to the plan ID. A mismatch stops the flow.

Key decisions#

  1. Offline and deterministic. Same input gives the same findings and IDs. This makes audits reproducible.
  2. No execution. Running unknown project code is the largest risk in migration tooling, so v0.2 does not.
  3. Verdict ceiling. The tool cannot know test results, so its best verdict is REVIEW_REQUIRED.
  4. Heuristic SQL checks, stated as such. A false claim of parsing would be worse than a clear limit.
  5. Skills separate from code. Skills guide hosts; the CLI works without any AI.

Roadmap (planned, not shipped)#

Runnable sandbox rehearsal, OpenRewrite and jscodeshift adapters, a database restore lab, OpenTofu plan review, and a team server. Each needs a threat model and tests before it is called implemented.
