# Support

- Bugs and feature requests: open a GitHub issue using the templates.
- Questions: open a GitHub Discussion or an issue labelled `question`.
- Security problems: do not open a public issue. Use the repository's private vulnerability reporting (see SECURITY.md).

This is a volunteer-maintained project with no SLA. Include the output of `migrasutra doctor` and, when relevant, the generated `audit.json` with secrets removed.
